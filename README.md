# Easy Logbook updates

Signed Android Phone and Car installers and their update feed. These are field-test releases.

Use **Settings → App updates → Check for updates** in Easy Logbook 0.25 or later. Android asks you to confirm installation. Finish your trip and park first. Install over the existing app without uninstalling.

The latest release contains separate Phone and Car APKs and `latest.json`. Private source, signing keys and logbook records are not stored here. Releases are published only from a verified successful build using the owner-triggered publication workflow. The workflow verifies original signing certificates, package, role, version, artifact digest and the matching bundled Car installer before publishing.
